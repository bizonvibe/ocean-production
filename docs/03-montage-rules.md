# 03. Правила монтажа

1. **Длина главы = озвучка** + 0.5 с до неё + 1.5 с после (`leadInFrames` 15, `tailFrames` 45).
   Последний план автоматически подгоняется под конец главы.
2. **80 / 20:** анимации ≈ 80 % длительности, стоки (`type: 'footage'`) ≈ 20 %. Допуск 15–25 % — иначе предупреждение.
3. **План ≤ 8 с.** Картинка заметно меняется не реже раза в 8 с (QC `scripts/qc_shots.py`, порог `QC_MAX_SHOT`).
4. **Без повторов:** два плана главы не должны быть похожи больше чем на 90 % (QC).
5. **Склейки по смыслу:** смена плана — на границе фразы или на ключевом слове (тайминги из `voice.captions.json`).
6. **Видеоряд следует за текстом:** диктор говорит о предмете — предмет в кадре.
7. **Подпись автора** на каждом стоковом плане и на анимации по чужой картинке.
8. **Акцентные слова** — 0–3 на главу.
9. **Музыка** всегда тише диктора; звуки — только на важных моментах.

QC запускается автоматически в `scripts/render.sh`; замечания — в `out/<имя>.qc.json`.
Порог длины плана можно поменять (`QC_MAX_SHOT=6 scripts/render.sh …`), когда определимся с темпом.
