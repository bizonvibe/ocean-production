# 01. Пайплайн главы

Все команды — из папки `video/`. `<проект>` — имя папки сценария в репозиториях-источниках, `chNN` — глава (`ch01`, `ch02`…).

## 1. Сценарий → главы
Для каждой главы выделить: описание видеоряда, слова диктора. Текст диктора сохранить в
`public/projects/<проект>/chNN/voice.txt` (абзацы через пустую строку — между ними будет пауза).

## 2. Озвучка (задаёт длину главы)
```bash
python3 scripts/tts.py public/projects/<проект>/chNN/voice.txt public/projects/<проект>/chNN/voice.wav --voice <голос>
pip install -r requirements-captions.txt     # один раз, тяжёлое (WhisperX)
python3 scripts/transcribe.py public/projects/<проект>/chNN/voice.wav --lang ru
```
Получаем `voice.wav` (−16 LUFS), `voice.json` (`durationMs`), `voice.captions.json` (тайминги слов) и
`voice.silences.json` (паузы в аудио). Драматические паузы вставляются **только в середину настоящей тишины**
(`gapAfter` в конфиге главы): тайминги WhisperX на границах слов неточны, разрез по ним обрывает звук.
Прослушать: ударения, числа, имена. Ошибочное ударение — переписать слово в тексте (например, «вОды» → «во́ды» или синоним) и перегенерировать абзац.

## 3. Материалы главы
Из трёх репозиториев скопировать папку `<проект>/<глава>/` в `public/projects/<проект>/chNN/`:
`stock/` (стоки + лицензии), `anim/` (картинки + ТЗ), `audio/` (музыка, звуки).
Прочитать ТЗ анимаций и файлы лицензий. Подписи авторов взять из файлов лицензий.

## 4. Раскадровка
По таймингам слов разбить главу на планы ([шаблон](../templates/storyboard.template.md)):
- **80 % длительности — анимации** по ТЗ, **20 % — стоки**; стоки ставить туда, где диктор говорит о реальном мире;
- смена плана на смысловых границах фраз; ни один план не стоит без движения;
- выбрать 0–3 акцентных слова (ключевая мысль, цифра, термин);
- музыка: трек из репозитория звука, звуки — на ключевые моменты.

## 5. Сборка
Главы собираются общим сборщиком `src/chapter/build.tsx` (`buildChapter`): раскадровка — список планов
со стартом по словам озвучки (`at('слово')`); сцена ТЗ получает якоря [секунда главы, секунда ТЗ], сток — файл
и подпись автора. Сцены ТЗ — `src/chapters/<проект>/chNN/scenes.tsx` на `SvgScene` (слои SVG, элементы по id/селектору).
Образец — `src/chapters/sperm-whale/ch05/ch05.config.tsx`.

- Скопировать `src/chapters/_example/ch01.config.tsx` в `src/chapters/<проект>/chNN.config.tsx`.
- Анимации по ТЗ — компоненты в `src/chapters/<проект>/chNN/` (базовые кирпичи: `AnimatedImage`, `components/ui.tsx`, сцены из `templates/scenes.tsx`).
- Добавить конфиг в `CHAPTERS` в `src/Root.tsx`. При регистрации в лог пишутся предупреждения: доля стоков не 15–25 %, раскадровка сильно не совпадает с озвучкой, слишком много акцентов.

## 6. Проверка и рендер
```bash
npm run typecheck
scripts/stills.sh <Composition> 60 300 600       # контрольные кадры → out/stills/
scripts/render.sh <Composition> <проект>-chNN    # → out/<проект>-chNN.mp4 (+ мастеринг и QC)
```
Посмотреть контрольные кадры до полного рендера. Заполнить [отчёт](../templates/delivery-report.template.md).

## 7. Сдача главы
Прислать MP4 пользователю в чат (+ краткий отчёт: длительность, доля анимаций/стоков, акценты, источники).
Правки — в конфиге главы, повторный рендер.

## 8. Финальная склейка
После одобрения всех глав:
```bash
scripts/join.sh <проект>-full out/<проект>-ch01.mp4 out/<проект>-ch02.mp4 ...
```
Главы начинаются из чёрного и заканчиваются в чёрное — склейка встык выглядит как затемнение.
Собрать общий список источников ([шаблон](../templates/credits.template.md)) для описания на YouTube.
