# 01. Пайплайн главы

Все команды — из папки `video/`. `<проект>` — имя папки сценария в репозиториях-источниках, `chNN` — глава (`ch01`, `ch02`…).

## 1. Сценарий → главы
Для каждой главы выделить: описание видеоряда, слова диктора. Текст диктора сохранить в
`public/projects/<проект>/chNN/voice.txt` (абзацы через пустую строку — между ними будет пауза).

## 2. Озвучка (задаёт длину главы)
Основной путь — **GitHub Actions `tts.yml`** (ключи `GEMINI_API_KEY`, `GEMINI_API_KEY_2` в Secrets; второй — когда
первый упёрся в квоту). Режимы: `chapter` (озвучка + паузы + тайминги слов, результат в ветке `voice`),
`align` (только тайминги слов, если выравнивание упало), `compare` (пробы голосов). Текст —
`voiceover/<проект>/NN/voice.txt` в этом репозитории. WhisperX ставится только на раннере (Python 3.12).

Уроки озвучки:
- **Запрос не длиннее ~1500 символов** (`--max-chars`, по умолчанию). На длинных кусках голос «уплывает»
  в роботизированный: так было в главе 3 «Кашалотов». `tts.py` проверяет центр спектра в начале и в конце
  и предупреждает «Голос уплыл» — тогда перегенерировать меньшими кусками.
- **Темп 110–125 слов/мин.** Посчитать: слов в `voice.captions.json` / `durationMs` × 60 000. Если быстрее
  (глава 4 вышла на 135), замедлить `ffmpeg -af atempo=0.91` (исходник сохранить как `voice.orig.wav`),
  пересчитать тайминги в режиме `align` и добавить паузы `gaps` в конфиге главы.
- Ошибки распознавания («бесполежны», «кошелоты») не исправлять в `voice.captions.json`: якорь `at('…')`
  пишется так, как распознано; повторяющееся слово — с номером вхождения `at('он', 2)`.

Локально (если ключ подставляет прокси окружения):
```bash
python3 scripts/tts.py public/projects/<проект>/chNN/voice.txt public/projects/<проект>/chNN/voice.wav --voice <голос>
pip install -r requirements-captions.txt     # один раз, тяжёлое (WhisperX)
python3 scripts/transcribe.py public/projects/<проект>/chNN/voice.wav --lang ru
```
Получаем `voice.wav` (−16 LUFS), `voice.json` (`durationMs`), `voice.captions.json` (тайминги слов) и
`voice.silences.json` (паузы в аудио). Драматические паузы вставляются **только в середину настоящей тишины**
(`gapAfter` в конфиге главы): тайминги WhisperX на границах слов неточны, разрез по ним обрывает звук.
Прослушать: ударения, числа, имена. Ошибочное ударение — переписать слово в тексте (например, «вОды» → «во́ды» или синоним) и перегенерировать абзац.

## 3. Материалы главы
Из трёх репозиториев скопировать папку `<проект>/<глава>/` в `public/projects/<проект>/chNN/`:
`stock/` (стоки + лицензии), `anim/` (картинки + ТЗ), `audio/` (музыка, звуки).
Прочитать ТЗ анимаций и файлы лицензий. Подписи авторов взять из файлов лицензий.

## 4. Раскадровка
По таймингам слов разбить главу на планы ([шаблон](../templates/storyboard.template.md)):
- **80 % длительности — анимации** по ТЗ, **20 % — стоки**; стоки ставить туда, где диктор говорит о реальном мире;
- смена плана на смысловых границах фраз; ни один план не стоит без движения;
- выбрать 0–3 акцентных слова (ключевая мысль, цифра, термин);
- музыка: трек из репозитория звука, звуки — на ключевые моменты.

## 5. Сборка
Главы собираются общим сборщиком `src/chapter/build.tsx` (`buildChapter`): раскадровка — список планов
со стартом по словам озвучки (`at('слово')`); сцена ТЗ получает якоря [секунда главы, секунда ТЗ], сток — файл
и подпись автора. Сцены ТЗ — `src/chapters/<проект>/chNN/scenes.tsx` на `SvgScene` (слои SVG, элементы по id/селектору).
Образец — `src/chapters/sperm-whale/ch05/ch05.config.tsx`.

- Скопировать `src/chapters/_example/ch01.config.tsx` в `src/chapters/<проект>/chNN.config.tsx`.
- Анимации по ТЗ — компоненты в `src/chapters/<проект>/chNN/` (базовые кирпичи: `AnimatedImage`, `components/ui.tsx`, сцены из `templates/scenes.tsx`).
- Добавить конфиг в `CHAPTERS` в `src/Root.tsx`. При регистрации в лог пишутся предупреждения: доля стоков не 15–25 %, раскадровка сильно не совпадает с озвучкой, слишком много акцентов.

## 6. Проверка и рендер
```bash
npm run typecheck
scripts/stills.sh <Composition> 60 300 600       # контрольные кадры → out/stills/
scripts/render.sh <Composition> <проект>-chNN    # → out/<проект>-chNN.mp4 (+ мастеринг и QC)
```
Посмотреть контрольные кадры до полного рендера. Заполнить [отчёт](../templates/delivery-report.template.md).

## 7. Сдача главы
Прислать MP4 пользователю в чат (+ краткий отчёт: длительность, доля анимаций/стоков, акценты, источники).
Правки — в конфиге главы, повторный рендер. Чек-лист перед отправкой — [03-montage-rules.md](03-montage-rules.md).

**Только музыка, звуки или громкость** (картинка не менялась) — без рендера кадров, за 1–2 минуты:
```bash
scripts/remix.sh <Composition> <проект>-chNN    # звук заново, видео из готового out/<проект>-chNN.mp4
```
Трек пользователя: измерить громкость (`ffmpeg -af ebur128`), в конфиге `musicVolumeFor(<LUFS>)`.
Трек короче главы — `durationSeconds` + `crossfadeSeconds` (петля с наплывом); длиннее — `once: true`.
Трек с большим динамическим диапазоном (трейлерный) — сначала сжать (compressor + loudnorm), иначе
кульминации перекрывают голос.

## 8. Фильм целиком
После одобрения всех глав:
```bash
scripts/film.sh <проект>-film <проект> <ПрефиксКомпозиций> <число глав>
# пример: scripts/film.sh sperm-whale-film sperm-whale SpermWhale 7
```
Порядок: заставка `Intro-KokoCrabs` → (слайд `Card-chNN` → глава) × N → концовка `Outro-Subscribe`.
Звук глав рендерится заново **без помастерного выравнивания**, весь фильм мастерится одним проходом —
соотношение голоса и музыки одинаково во всех главах. Заставка и концовка −17 LUFS, слайды глав без звука.
Названия и подзаголовки слайдов — `CHAPTER_CARDS` в `src/intro/ChapterCard.tsx`.
`scripts/join.sh` — простая склейка готовых MP4 встык (без заставки и единой громкости).

**Отдача файла.** В чат файлы больше ~250 МБ не проходят: в чат — сжатая копия
(`ffmpeg -c:v libx264 -crf 21 -c:a copy`), полное качество — в отдельную ветку `film` через Git LFS
(хост `lfs.github.com` в окружении), ссылка вида `https://github.com/<владелец>/<репозиторий>/raw/film/<файл>.mp4`.
После скачивания ветку удалить: LFS-хранилище GitHub ограничено.

## 9. Публикация на YouTube
- Описание, тайм-коды глав, источники и теги — `credits/<проект>-youtube.txt`
  (образец `credits/sperm-whale-youtube.txt`, правила — [02-style-guide.md](02-style-guide.md)).
- Тайм-коды: старт слайда каждой главы по длительностям частей в `out/film-tmp/`, первая глава 0:00.
- В YouTube Studio отметить «изменённый или синтетический контент» (голос диктора синтезирован).
- Обложка канала — `Banner-KokoCrabs` (2560×1440), проверка безопасной зоны — `Banner-KokoCrabs-safe`:
  `npx remotion still src/index.ts Banner-KokoCrabs out/banner-koko-crabs.png`.
