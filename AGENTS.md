# Ocean Production — правила монтажа

Ocean Production — **инструменты и правила монтажа**. Медиа здесь не хранится: материалы для каждого
сценария лежат в трёх репозиториях-источниках, а агент (Claude) сам берёт из них нужное для каждой главы
и монтирует ролик этим проектом.

| Репозиторий | Что в папке `<проект>/<глава>/` |
|---|---|
| Звук | музыка и звуки |
| Анимации | картинки и ТЗ, как их анимировать (анимацию делает агент здесь) |
| Стоки | видео и картинки (имя файла = ключевое слово), текстовый файл с лицензией/автором |
| **Ocean Production** | Remotion-проект, скрипты, правила — монтаж |

## Порядок работы

1. Получить сценарий, разбить на главы (видеоряд + слова диктора).
2. **Сначала озвучка главы** (`scripts/tts.py`), затем тайминги слов (`scripts/transcribe.py`). Длину главы задаёт озвучка.
3. Взять материалы главы из трёх репозиториев, скопировать в `video/public/projects/<проект>/chNN/` (в git не идут).
4. Раскадровка под длину озвучки: **80 % анимации, 20 % стоки** (видео или картинки).
5. Собрать главу: `video/src/chapters/<проект>/chNN.config.tsx` + свои анимации рядом; зарегистрировать в `video/src/Root.tsx`.
6. `npm run typecheck`, контрольные кадры `scripts/stills.sh`, рендер `scripts/render.sh`.
7. Прислать главу пользователю в чат. Следующая глава — после проверки.
8. Когда все главы одобрены — `scripts/join.sh` склеивает их в один ролик.

Подробно: [docs/01-pipeline.md](docs/01-pipeline.md).

## Неизменные правила

- **Формат:** 1920×1080, 30 fps, горизонтальный (YouTube), H.264, звук −14 LUFS.
- **Озвучка:** русский язык, Gemini TTS, мужской спокойный голос документального диктора. Голос выбирает пользователь — после выбора записать его в [docs/02-style-guide.md](docs/02-style-guide.md) и использовать во всех главах.
- **Доля планов:** около 80 % длительности главы — анимации, около 20 % — стоки.
- **Подпись автора** мелким шрифтом внизу на каждом стоковом плане (из файла лицензии в репозитории стоков). Анимация по чужой картинке — тоже с подписью.
- **Субтитров нет.** Только изредка акцентное слово в кадре (0–3 на главу), на важном слове диктора.
- **Музыка всегда тише диктора** (по умолчанию ≈ −17 дБ к голосу). Подъём музыки в паузах диктора ≥ 5 с — экспериментальная опция `boostInPauses`.
- Ключи API — только как network secret окружения, никогда в коде, конфигах и чате ([docs/05-api-keys.md](docs/05-api-keys.md)).
- Готовые ролики, исходники и материалы проектов в git не коммитим (`video/out/`, `video/public/projects/` в `.gitignore`).
